# Meowslim Landing Page

A coming-soon landing page for Meowslim, a customizable Muslim avatar creator.

## Deploy to Vercel

Import `kolapoimam/meowslim-landing` in Vercel. Choose **Other** as framework preset, leave the build command empty, and use the repository root as the output directory.

This is a static HTML, CSS and JavaScript site. No dependencies or environment variables are required.

The illustrated avatar previews are placeholders; the final downloadable PNG avatar creator is under development.
