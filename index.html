What is Meowslim?

Meowslim is an avatar generator built around Islamic modesty. Pick a style, or simply give it a name, and it draws a friendly character dressed the way you would dress: covered, dignified and recognisably you.

Like DiceBear, every avatar is generated in code from a seed, so the same name always returns the same face. That makes Meowslim as useful inside apps and products as it is on your own profile.

Modest by design

Every outfit and head covering follows Islamic dress codes. Nothing to filter out, nothing to second-guess.

Highly customisable

Mix head coverings, beards, expressions and colours until it feels right.

Developer-friendly

The same seed always draws the same avatar, and an API is planned so your app can give every user a default.

Community-centred

Built for Muslims, by Muslims, with the waitlist helping decide what ships first.
